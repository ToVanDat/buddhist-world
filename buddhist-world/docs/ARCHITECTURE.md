# Kiến trúc
- **Client (apps/web)**: React lo UI; R3F lo render. Input nằm ở object mutable (`game/core/input.ts`), snapshot mạng ở `Map` (`multiplayer/socket.ts`) → không re-render theo frame. Zustand chỉ giữ state "thưa" (auth, cài đặt, trạng thái mạng, danh sách id).
- **Server (apps/server)**: REST (auth, me, health) + Socket.IO. Postgres giữ dữ liệu bền; Redis giữ rate-limit + presence.
- **Mạng**: client gửi `{p, yaw, anim, seq}` ≤15 Hz (volatile). Server kiểm tra sequence, tốc độ, bounds và (khi navmesh đã được export) vị trí/đường đi trên navmesh; tick 10 Hz gửi snapshot theo bán kính 80 m trong cùng region. Sai → `player:correct`. Production từ chối join region nếu navmesh khai báo nhưng thiếu. Presence heartbeat/snapshot/voice relay phải khớp `ownerToken` với lease hiện hành; khi Redis không xác minh được ownership, gateway không phát local-only snapshot. Các yêu cầu region join được tuần tự hóa theo socket.
- **Phiên**: mỗi user có một game session active. Access JWT 15' gắn session UUID; refresh token ngẫu nhiên, chỉ lưu hash trong DB, cookie httpOnly. Refresh xoay token ngay trên cùng một row/session ID; hash token cũ được lưu dưới dạng SHA-256 trong audit log. Yêu cầu refresh trùng lặp do nhiều gateway đọc token cũ trước khi transaction đầu commit nhận `409` trong cửa sổ `REFRESH_ROTATION_GRACE_MS` (mặc định 5 giây), không thu hồi phiên và không xóa cookie; replay sau cửa sổ này thu hồi session. Cột family_id cũ chỉ giữ tương thích schema, không còn dùng trong runtime.
- **Mở rộng**: thêm region = thêm manifest. Socket.IO Redis adapter, distributed socket ownership/fencing, Redis presence và DB `owner_epoch` đã có source; checkpoint được fence theo epoch. Cần reconnect storm/soak test để xác minh multi-instance dưới tải. Region ownership và chunk streaming chưa được nghiệm thu.
- **Character**: player GLB yêu cầu skin/root bone và Idle/Walk/Run/Jump; NPC GLB yêu cầu skin/root bone và Idle/Walk/Talk/Pray/Work/Rest. `AvatarMotion` là trạng thái runtime, còn gameplay action là command/event riêng. GLB lỗi/tải chậm dùng procedural fallback.
